# Aplikasi Belajar Interaktif

Aplikasi belajar Semester 1 (PJJ Sistem Informasi, Universitas Siber Muhammadiyah).

- Aplikasi: `index.html` (dibuka lewat GitHub Pages: https://gilraku.github.io/aplikasi-belajar/)
- Sumber: `sumber/` — jalankan `node build.js` di dalam `sumber/` (output ke `sumber/out/`), lalu salin hasilnya ke `index.html`.
- Progres belajar tersimpan per orang di browser (localStorage), bisa diekspor/impor lewat tombol **Progresku**.
